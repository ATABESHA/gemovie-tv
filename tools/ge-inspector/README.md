# GE Inspector

A small Chrome / Edge extension: paste a ge.movie address, press **Check**, and it shows
what the MyMovie TV app sees on that page (lists, titles, posters, filters, pages,
description, age rating, player address, and which parts the app uses).

It reads pages with the same code as the TV app. It only opens ge.movie.

## Install (one time)
1. Download this `ge-inspector` folder and unzip it somewhere (for example Documents).
2. Open `chrome://extensions` (Edge: `edge://extensions`).
3. Switch on **Developer mode**.
4. Click **Load unpacked** and choose the `ge-inspector` folder.
5. Click the puzzle icon in the toolbar → pin **GE Inspector** → click it.
